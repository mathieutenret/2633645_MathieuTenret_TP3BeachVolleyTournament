À propos

Bienvenue dans notre application de gestion de tournois de Beach Volley !

Cette application vous permet de gérer des tournois de Beach Volley 2 contre 2.

Chaque tournoi peut contenir 16 équipes au maximum.

Une équipe peut être créée avec un seul joueur si celui-ci recherche un partenaire, via l'onglet "Équipe 1 joueur".

Une équipe complète est composée de deux joueurs. Elle peut être directement créée via l'onglet "Équipe 2 joueurs".

Une équipe de un joueur peut être complétée via le bouton "Ajouter un partenaire" de la page "Tournois".
